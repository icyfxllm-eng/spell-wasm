This build is about the menu telling the truth. Three rows in it were lying, in different ways, and one mode is gone entirely.

Say It is removed. Tapping it either did nothing or opened the voice-spelling guide instead, because the button it pressed had quietly been handed to a different feature months ago. It had no way in of its own at all. Rather than repair a mode with no door, it is gone.

The "Spell It" row is also gone from the menu, and this one was never broken — it was the game you were already looking at. The menu opens on top of the main game, so tapping that row closed the menu and arrived, which looks exactly like a dead row. Closing the menu still gets you there. There is simply no row claiming to take you somewhere new.

"How this works" — the guide for spelling out loud with the mic — now lives in Help & Settings, and this is the real fix: it used to appear once, the first time, and then you could never get it back. Now you can reopen it whenever you like, and opening it from Settings just shows you the guide instead of dropping you into a round.

Letter Forge has its own icon at last. It and Spelling Bee both showed a bee, so the menu read as two versions of one mode. The forge is a hammer now.

The mic itself has not moved. It is still beside where you type, on the play screen, exactly where it was.

What is most useful now:

• Open the menu and tap every row, in whatever language you play in. Every one should go somewhere. If a row does nothing, that is the single most useful thing you can report.
• The Spelling group should read Practice, Spelling Bee, The Climb, Daily and Head to Head. Tell me if you see anything else there, or if something you expected is missing.
• Open Help & Settings and tap "How this works". It should show the four-step guide and close again without starting a round.
• If you use the mic to spell out loud: it should behave exactly as before. Any change there is a bug, not an intention.

New here? Tap the glowing orb to hear a word, then spell it on the keyboard and press Check. Everything works offline after the first load.
