A diagnostic build. The voice spelling still is not working, and this build exists to find out exactly why rather than to guess again.

The last build fixed a real problem — the phone's audio system was taking the microphone away whenever a word played — but the letters still are not appearing, so something else is also wrong. The difficulty has been that "no letters" looks identical from the outside whether the app is hearing silence, hearing you perfectly but failing to pass it on, or never starting to listen at all. Those are three different faults with one symptom.

So this build counts what happens at every step: how much sound arrives, how loud it is, whether it reaches the part that recognises speech, how many results come back, and any error. One screenshot now separates all three.

Two real fixes came with it. The app was briefly throwing away the first fraction of a second of audio after you tap the mic — short, but it is exactly when you would start saying the first letter. And the diagnostic line itself was thinner on newer iPhones, so on some devices it was hiding the very information needed to fix this.

What is most useful now:

• Tap the orb, tap the mic, say "C, A, T", and send me a photo of the diagnostic line. That single line is worth more than any description of what happened.
• If no diagnostic line is visible, tell me — that is itself useful.
• Everything else should behave exactly as before. If word audio, Replay, Slow or the silent switch changed in any way, that is a bug, because nothing in this build was meant to touch them.

Voice spelling is still the only thing being worked on here. Spelling with the keyboard is unaffected, and if you do not use the microphone this build changes nothing for you.

New here? Tap the glowing orb to hear a word, then spell it on the keyboard and press Check. Everything works offline after the first load.
