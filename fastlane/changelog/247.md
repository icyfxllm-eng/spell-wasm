Another housekeeping build — nothing in it changes what you see or hear.

Two of these in a row, so here is the honest reason. The work behind this one is a navigation menu that will eventually put every game mode two taps away, instead of some of them hiding behind a gamepad icon that does not say what it opens. It is built, but it is switched off: only a development build can open it, and this build is not one. Turning it on is a later step, and you will know when it happens because the home screen will look different.

The part of it that is live is invisible on purpose: the list of game modes now has one source instead of two, so a mode can no longer be reachable from one place in the app and missing from another. That is the kind of bug that makes an app feel untrustworthy without anyone being able to say why.

The most useful things to try are still the ones from the last few builds:

• The Spelling Bee's audio, which changed completely in build 244.
• "Can't hear it", in SpellDoku, Spell Search, Spell Cross and Spell Picture.
• If you play in Arabic: typing the short-vowel marks no longer marks you wrong (build 246).

If a word is hard to make out after hearing it slowly, tell us the word and the language. That is still the single most useful thing you can send us, and it is how three real problems have been found so far.

New here? Tap the glowing orb to hear a word, then spell it on the keyboard and press Check. Everything works offline after the first load.
