# Common-password blocklist for Spell accounts (CC-ONBOARD-JR F9 / D3).
#
# One entry per line, lowercase. A password is refused when its lowercased form
# OR its letters-only core matches a line here, so "Password1!" is caught by
# "password" while a real passphrase is not.
#
# Composition rules alone (8+, a digit, a symbol) still wave through the exact
# passwords attackers try first: "Password1!" satisfies every rule. This list is
# the part that refuses them. It is a seed of the most-guessed entries, meant to
# be appended to, not a full corpus — a leaked-password service would be better
# and needs a network call this backend deliberately does not make during signup.
#
# Deliberately NOT listed: "example", because F9's own passing case is
# "Example5%". A blocklist that fails the spec's example is a broken blocklist.
