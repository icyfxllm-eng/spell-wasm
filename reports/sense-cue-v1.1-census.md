## C1: format of the three tables

- `assets/words/{en,es,ru}/homophones.txt`. Plain text, generated by `tools/build_collisions.py`, one set per line, members separated by whitespace, `#` comment lines at the top (generator banner and set count). en 263 sets over 3,158 rows; es 11 over 6,267; ru 34 over 6,833. en and es also have a hand-maintained `homophones.seed.txt` (variety pairs that must keep grading after one spelling left the bank).
- **Status header: yes.** Every reader found in C2 skips lines starting with `#`, so a `# status: verified` line is safe today.
- **Per-set `kind`: no, not in this format.** Readers split each line on whitespace and treat every token as a member (`src/homophones.rs` `split_whitespace`, `scripts/audio-verdicts.mjs`, `tools/human-audio/qc.py`). A `kind:accent` token would become a fake member. There is no set id either: `src/homophones.rs` uses the line number as the group id, which changes whenever a set is added above it.
- Conclusion: F1 needs the migration path (one structured file per language), not an extension of these files.

## C3: what an empty table locks today

**Nothing.** In `src/homophones.rs`, a language with no file has an empty table, and `accepts` returns `false` (line 84: `if t.is_empty() { return false; }`). The module doc says so: "A language with no homophone file simply has an empty table and this layer is a no-op." `group_members` returns an empty list, so Spelluzzle, Spell Cross and the rest just see no sets.

So today an empty table does not fail closed. It **fails strict**: in the 12 languages without a table, a learner who types a real sound-alike of the prompt is marked wrong. That is the fairness gap the parent spec exists to close, and it is live now. The only "fail closed" in play is CC-IMPOSSIBLE's homophone rule, which is a spec, not code.

So H1 ("`missing` turns off cues, bonus and Impossible; Normal grading unchanged") **is not a reversal** of existing code. No SENSE-CUE v1 text was found to check it against (item 1 above).
