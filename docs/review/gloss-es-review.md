# Spanish gloss — review sheet

258 rows. Signing this file is the ONLY thing between the translator
and being usable: the tables, loader, CI and resolver are all done, and every
language renders one row until a native speaker signs it.

HOW TO REVIEW: each line is `spanish_word — english_concept`. Mark anything
wrong or awkward. You are NOT checking spelling (every key is already a live
word in the Spanish bank) — only whether the pairing is the sense a child
would expect.

WHEN DONE: set `"audited": true` and `"auditor": "<name>"` in
config/gloss/es.json. Nothing renders until both are set.
