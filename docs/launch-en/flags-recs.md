# CC-LAUNCH-EN: recommendations for the 38 default-ON flags

Source: `node scripts/flags-audit.mjs` (38 flags, all `ship:null` in config/flags.release.json), main @ launch-en/phase-a, 2026-11-07. Read-only research. Recommendations only; Eric initials.

**Summary**
- 20 SHIP, 18 OFF. Seven of the 18 are `spelluzzle_*` v1.1 sub-flags and three are `board*` polish flags, so only 8 independent features are off.
- Riskiest calls: (1) `en_retier` OFF removes the 1,210-word Expert/Hard growth that every TestFlight build since 2026-10-19 has carried, but the repo records an open regrade question for it. (2) `spelluzzle` SHIP rests on automated tests and Eric's build-278/279 device pass, whose verdict is not recorded anywhere in the repo. (3) `def_match` OFF drops the only "Meaning" tile because it cannot work without `/api/defpool`.
- No row has a recorded line "acceptance tests passed" in a spec file. Specs are mostly `Status: REVIEW-GATED`, and some specs are not in the repo (CC-SPELLUZZLE, CC-BOARD-GAME, CC-RANDOSPELL, CC-LETTER-FORGE as own files). "Evidence" below is therefore the strongest available proxy: Eric-signed go-live commit, unit-test count (`#[test]` in the module), and named e2e spec (existence only; I did not run them). tests/e2e/TEST-REPORT-app.md says 522/522 but I did not verify its date.

## Cross-cutting facts (apply to every row)

- **Audio offline (all modes).** src/api.rs:75-97: source order is Human, Pack, ServerCache, then NativeTts (AVSpeech, "offline"); a failed server clip falls through to on-device TTS and shows a one-line banner. So no mode is silent offline on iOS. Gap, from recon.md: `storage::fetch_text` and the ServerCache fetch set no timeout (src/storage.rs:49-63), so a hung (not refused) server is bounded only by the WebView default. No "offline state" screen exists. Marked "audio fallback" below.
- **English audio caveat.** About 1,191 re-tier words have clips only in the server cache, none bundled (recon.md item 5). Offline those words use AVSpeech; reports/en-retier-audio-check.csv lists ~30 words whose server clip is already garbled (caisson, brougham, ...).
- **Release flag reader.** Per flags.rs, a release build ignores localStorage for every non-player flag, so `ship:false` is a real off. Only the 6 `PLAYER_FLAGS` (syllable_replay, photo_list, spell_aloud, word_stories, online_spelloff, attempts_shields) keep reading the player's own choice; for them the release default is only the starting value.
- **Non-English leak.** Several registries still list es (randospell `["en","es"]`) or all 15 languages (def_match, practice, spelldoku, wordsearch, wordcross). Whether any of that is visible in an English-only build depends on the F3 play-language registry change, which recon.md says is not built. Each row says "English path OK" where the English path itself works; the leak is a F3 matter, not a flag matter.
- **Registry status.** config/modes.json: `ghost_racing`, `syllable_replay`, `spell_aloud` are `status: hidden` (no tile); `photo_list`, `progress_report` carry `requiresPremium`.
