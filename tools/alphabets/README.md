# Alphabet program generators

These scripts render canonical glyph forms from FREE fonts, thicken to
field spec, optically center (ink center-of-mass on canvas center), and
audit through the suggester. Fonts are fetched, not vendored (except
DejaVu in tools/fonts): DejaVu (Bitstream Vera license) from
github.com/dejavu-fonts; Noto Sans Arabic / Devanagari / KR / JP / SC
(SIL OFL 1.1) from github.com/google/fonts/tree/main/ofl/.
